# 🚀 Slogohod-demo

Интерактивное веб-приложение для обучения детей чтению по слогам. Проект построен на современной архитектуре с фокусом на масштабируемость и поддерживаемость.

> 🎯 **Демо-версия**: 44 слова для проверки механики. Полная версия рассчитана на 5000+ слов.

### 🎨 Frontend

- **Framework**: [Nuxt 3](https://nuxt.com/) - современный Vue-фреймворк
- **Язык**: TypeScript - строгая типизация всего приложения
- **Стилизация**: 
  - [Tailwind CSS](https://tailwindcss.com/) - основной инструмент стилизации
  - **Кастомный плагин** - автоматическая генерация CSS-переменных из конфига
  - **CSS Custom Properties** - гибкая система тем
  - Полноценный **Dark Mode** (`theme-dark`/`theme-light`)
- **Контент**: [@nuxt/content](https://content.nuxt.com/) + SQLite для работы с YAML

### 🏗️ Архитектура

- **Методология**: [Feature-Sliced Design](https://feature-sliced.design/) с четким разделением ответственности (entities/features/widgets)
  - Масштабируемая структура, готовая к 5000+ словам
  - Автоимпорты типов и алиасы (`@features/*`, `@widgets/*`)
- **Качество кода**: 
  - [Prettier](https://prettier.io/) — единый стиль форматирования
  - **Строгая типизация** всех компонентов и модулей
  - Полная поддержка IDE за счёт TypeScript

### 💾 Данные

- **Система хранения на YAML** с автоматической индексацией в SQLite через `@nuxt/content`
- Иерархическая структура: `level-1/names/a/anya.yml`
- Полная типизованная модель с валидацией через **Zod**
- Кастомный тип диапазона чисел `Enumerate` для сложности (1-12)

### 🎮 Текущий функционал

- **Два рабочих виджета**:
  - `SyllableCard` — обучение по слогам с визуальной обратной связью
  - `SyllableLevel` — прогресс и навигация по 15 словам

### 🎨 UI/UX и дизайн-система

- **Кастомная система тем** на CSS-переменных:

  ```css
  :root { /* светлая тема */ }
  .theme-dark { /* тёмная тема */ }
  ```

- Автоматическая генерация переменных из tailwind.config.ts через кастомный плагин
- Плавное переключение между темами без перезагрузки
- Адаптивный дизайн с крупными элементами (детское восприятие)

- Единый код-стайл обеспечен Prettier для консистентности всего проекта

## ⚡ Оптимизация и производительность

### 📦 Vite — тонкая настройка сборки

Проект использует **кастомную конфигурацию Vite** для максимальной производительности:

#### 🧩 Плагины

- **nodePolyfills** — полифиллы для Node.js модулей (`buffer`, `util`, `stream`, `crypto`), 
  обеспечивающие совместимость с браузерным окружением
- **compression** — автоматическая **Brotli-компрессия** всех статических ассетов:
  - JavaScript (`*.js`)
  - CSS (`*.css`)
  - HTML (`*.html`)
  - SVG (`*.svg`)

#### 🎯 Оптимизация зависимостей

- **Ручное управление** предзагрузкой (`optimizeDeps.include/exclude`)
- Тонкая настройка через `esbuildOptions`:
  - **Target**: `esnext` — использование современных возможностей JS
  - **Global**: `globalThis` — корректный глобальный контекст
  - **Legal comments**: `none` — удаление лишних комментариев
  - **Drop**: `['console', 'debugger']` — очистка продакшн-сборки от отладочного кода
  - **Support**: `bigint` — поддержка больших чисел
